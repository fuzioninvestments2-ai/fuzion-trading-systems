02

El corazón — cómo piensa cada motor

Son dos motores, uno por bot. Los dos piensan con estos mismos pasos, pero cada uno afinado a su mercado (el real es más cauto). En cada paso hay una razón de trader; a la derecha, el archivo del código que lo hace (para que aprendas dónde vive cada cosa).

1

Reúne las velas de todos los tiempos

De 5s a 1d, en vivo y del historial guardado.

Sin datos limpios no hay lectura. Cuantos más tiempos, más completa la foto del mercado.

candles.py · history.py
2

Filtra el ruido

Suaviza los micro-saltos con una media exponencial.

Un tick suelto puede ser un salto falso. Suavizando, los indicadores leen la tendencia real, no cada temblor.

deep_analysis.py
3

8 indicadores votan en cada tiempo

RSI · MACD · Bollinger · Medias · Estocástico · Donchian · VWAP · Patrones. Cada uno dice sube / baja / neutral.

Ninguno decide solo. Es un panel de opiniones, como varios analistas mirando el mismo gráfico.

scoring_strategy.py
4

Pondera los votos

No todos pesan igual: según el tiempo, el régimen (ADX: rango o tendencia) y lo que históricamente acierta en ese activo.

En tendencia mandan MACD y medias; en rango mandan los rebotes techo/piso. El bot aprende y sube el peso de lo que funciona.

scoring_strategy.py · weight_learning.py
5

Cada tiempo da su opinión

Dirección (sube/baja) + confianza (0–100%).

El umbral de confianza se calibra con el historial: cada activo tiene su punto justo.

deep_analysis.py · calibration.py
6

Mide la ALINEACIÓN

¿Cuántos tiempos coinciden en la misma dirección?

Esa es la fuerza. Muchos tiempos coincidiendo = señal fuerte; peleados entre sí = no operar. Es la idea central del sistema.

deep_analysis.py
7

Aplica protecciones

Tendencia mayor (no ir contra el diario) · compresión (squeeze, previo a ruptura) · solo real: horario + noticias de alto impacto.

Aquí el bot calla cuando el mercado no es claro o es peligroso. La protección es tan importante como la señal.

manipulation.py · market_hours.py · news_filter.py
8

Veredicto

OPERAR · OPCIONAL · NO OPERAR, con dirección y hora exacta de entrada.

Y se registra para, más tarde, medir si acertó (win-rate real) y aprender de verdad.

telegram_signals.py · signal_log.py

Vocabulario (para leer las señales)

Alineación% de tiempos que coinciden en la misma dirección. Alta = acuerdo entre plazos.
Régimen (ADX)Si el mercado va en tendencia (slide) o en rango (oscillate). Cambia qué indicadores mandan.
Compresión (squeeze)Las velas se estrechan: rango apretado, posible ruptura. Entrada por el tiempo corto.
Tendencia mayorLa dirección del tiempo más largo. No operar en contra de ella (alto riesgo).
03

Configuración de tiempos

Se GUARDAN (datos para leer)

16 temporalidades · 5s → 1d

5s10s15s30s 1m2m3m4m5m 10m15m30m 1h2h4h1d

Toda la escala se lee para la alineación. Un tiempo sin ≥6 velas se ignora solo.

Se OPERAN (expiración)

7 temporalidades · 1m → 30m

1m2m3m5m 10m15m30m

Los segundos (5s–30s) son el clic del análisis (afinan la entrada), no expiraciones. Igual en OTC y en real.

06

Cómo nace una señal

Paso 1

Datos de todos los tiempos

Guarda velas de 5s a 1d, en vivo y hacia atrás.

Paso 2

Lectura envolvente

Lee toda la escala: cuántos tiempos coinciden (alineación).

Paso 3

Entrada afinada

Los segundos son el “clic” del análisis, no la orden.

Paso 4

Orden en 1m–30m

La señal se opera en tus tiempos: 1m a 30m.

07

Comandos

En PowerShell, dentro de la carpeta del proyecto (cd $env:USERPROFILE\fuzion-trading-systems). El # es un comentario, no se escribe.

Encender los bots OTC Real

Cada bot en su ventana. Doble clic al .bat o por comando.

.\INICIAR_OTC.bat # Fuzion POption OTC
.\INICIAR_REAL.bat # Fuzion POption FX

Datos OTC OTC

Bot de Telegram apagado en esa cuenta (una conexión por SSID).

python -m bot.download_history --all --batch 5 # todos los OTC, 5s→1d
python -m bot.download_history EURUSD_otc # un activo
.\ROBOT_AUTO.bat # robot 24/7 (baja + sube)

Datos del mercado real Real

yfinance anytime; PO solo con mercado abierto; TradingView por CSV.

python -m bot.historical_loader # yfinance 1m→1d (años)
python -m bot.download_history --real # PO 5s→1d (mercado abierto)
python -m bot.tradingview_import EURUSD tf5 archivo.csv # CSV de TradingView
.\ROBOT_REAL.bat # robot real sincronizado

Respaldo en la nube OTC Real

Exporta y sube (el tesoro, siempre respaldado).

python -m bot.dataset_export export OTC # → datasets/otc
python -m bot.dataset_export export REAL # → datasets/real
git add . ; git commit -m "datos" ; git push # respaldo a GitHub
08

Cómo lo enciendes (doble clic)

INICIAR_OTC.batOTC

Arranca el bot OTC en Telegram. Úsalo para pedir señales OTC (24/7).

INICIAR_REAL.batReal

Arranca Fuzion POption FX en Telegram. Úsalo cuando el mercado real esté abierto (Lun–Vie).

ROBOT_AUTO.batOTC

Robot que baja y acumula el historial OTC 24/7 y lo sube a la nube. Se reinicia solo.

ROBOT_REAL.batReal

Robot del real, sincronizado con el horario: siempre refresca años (yfinance) y, al abrir el mercado, baja 5s→1d de PO. Déjalo armado desde ya.

Regla de oro: una cuenta de PO = una conexión. El OTC usa la cuenta 1 y el real la cuenta 2, así pueden correr a la vez. No enciendas dos cosas sobre la misma cuenta al mismo tiempo.

09

Tu día a día

Fin de semana → mercado real cerrado. Usas Fuzion POption OTC (24/7) y dejas corriendo ROBOT_AUTO y ROBOT_REAL (este último solo junta datos hasta que abra).

Domingo noche (~22:00 UTC) → reabre el real. ROBOT_REAL empieza solo a bajar 5s→1d de PO. Para señales en vivo, enciendes INICIAR_REAL.

Pedir una señal en Telegram → abres el bot → eliges mercado/par → eliges tiempo (1m–30m) → “Iniciar análisis”. El bot lee y responde con dirección, alineación y aviso.

Honesto

El 90–95% es la experiencia del trader; el bot mide su acierto real con su registro. Sin datos de las 12 temporalidades → NO OPERAR (no inventa).

🛡️ Barrera anti-basura

Antes de leer, se descartan las series basura (planas, NaN, corruptas, saltos imposibles) para no producir señales absurdas. Limpieza de disco: python -m bot.data_quality [otc|real] [--borrar]. Archivo: data_quality.py.

⚡ Recopilación por evento (rápida)

El escaneo avanza EN CUANTO llegan las velas (no espera fija), fija el activo una sola vez y omite el 2h (que PO no sirve). Descarga profunda ~3–4× más rápida, mismo resultado. Archivos: pocket_service.scan_backwards · download_history.

Fichas dedicadas: Biblioteca del cerebro (indicadores + matemática), Sistema OTC y Sistema Real (documentos aparte). Ver progreso de datos: python -m bot.progreso.

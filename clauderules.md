# Reglas Obligatorias del Proyecto

1. **Desarrollo Modular Progresivo:** Prohibido avanzar al siguiente archivo o
   módulo hasta que el actual haya sido probado y validado por el usuario.

2. **Control de Modificaciones:** Cada cambio en el código debe estar comentado
   explicando la lógica o fórmula matemática usada.

3. **Gestión de Errores:** Todo script que use WebSockets o APIs debe incluir
   sistemas de reconexión automática try-except.

4. **Validación:** Antes de dar por terminado un archivo, debes presentar un
   script corto de prueba en la terminal para verificar su funcionamiento.
